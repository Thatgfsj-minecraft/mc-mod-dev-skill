# Minecraft 1.21.11 ↔ 26.x API / 工具链差异（26.1–26.3 已实测）

> **环境限定知识（已验证）**：验证于 **1.21.11 ↔ 26.1.2 / 26.2 / 26.3**，sky-islands 四构建 ×3 线编译 + Fabric 服务器冒烟全过（bot E2E：26.1 过，26.2/26.3 因 minecraft-data 缺协议定义跳过）。
> **最大断层：26.x 去混淆化**——这不是普通的小版本 API 变化，工具链写法整体换代。

## 1. 构建系统断层（必改，编译前）

- **Mojang 停发混淆映射**：26.x version JSON 无 `client_mappings`/`server_mappings`，jar 本体即 mojang 名（启动日志 `Mappings not present!`），无 remap 管线、无 remapJar。
- Fabric Loom：插件 id **`fabric-loom` → `net.fabricmc.fabric-loom`**（旧 id 只服务混淆版本），**删除 mappings 行**，`modImplementation` → **`implementation`**。Loom 1.17.21 全系不可用（报 "Failed to find official mojang mappings"），用 **1.18.2**。
- **Java 25 硬性要求**（version JSON majorVersion=25，Loom 配置期硬校验）：Gradle daemon、编译 toolchain、服务器运行时、`depends.java >=25`、`options.release=25`。
- Gradle：Loom 1.18.2 声明 plugin-api 9.7.0 → wrapper **≥9.7**（实测 9.7.0/9.7.1/9.8.0 均可跑在 JVM 25）。
- ModDevGradle 2.0.147 **无需升级**即可处理 26.x neoform（26.1.2-1 / 26.2-2 / 26.3 冷跑 22-24 分钟均成功）。**陷阱**：本机无 JDK 25 toolchain 可探测时，MDG 走供应商下载路径引用 `JvmVendorSpec.IBM_SEMERU`，该枚举 Gradle 9 已删 → 配置期崩；先装好 JDK 25 再构建。

## 2. 核心 API 变更（26.1 起）

| 1.21.11 | 26.x |
|---|---|
| `new SavedDataType<>("字符串", supplier, codec, DataFixTypes)` | **首参改 `Identifier`**：`new SavedDataType<>(Identifier.fromNamespaceAndPath(ns, path), …)`——编译器可抓；id 命名空间化后磁盘布局变为 `world/dimensions/<维度>/data/<ns>/<path>.dat`（全局数据在 `world/data/<ns>/`） |
| `DimensionDataStorage` | **改名 `SavedDataStorage`**（26.3 起；`getDataStorage().computeIfAbsent` 调用写法不变） |
| `ServerEntityWorldChangeEvents.AFTER_PLAYER_CHANGE_WORLD` | **`ServerEntityLevelChangeEvents.AFTER_PLAYER_CHANGE_LEVEL`**（fabric-entity-events-v1，回调 `afterChangeLevel(ServerPlayer, ServerLevel, ServerLevel)` 形状不变） |
| `net.minecraft.resources.Identifier` | **不变**（26.x 仍 Identifier、仍在 resources 包） |
| `MinecraftServer.setRespawnData(LevelData.RespawnData.of(...))` | **不变** |

适用边界：§2 前三条在 26.1/26.2/26.3 三线均实测成立；26.4+ 未验证。

## 3. worldgen 数据包变更（26.3 大改）

- **26.1 / 26.2**：noise_router 与 1.21.11 同键（`preliminary_surface_level` 仍有效，javap + 常量池双证）；world_preset / tag 路径与格式不变。
- **26.3**（重写级）：
  - `preliminary_surface_level` → **`chunk_surface_level`**；`NoiseRouter` record 15 参 → **8 参**（barrier/lava/fluid_level_*/vein_* 移入可选 `Aquifers$Config`）；
  - `surface_rule` → **`material_rule`**；`aquifers_enabled` → **`aquifers`**（Optional 对象，缺省=关）；`ore_veins_enabled` 删除；
  - `NoiseSettings` record 缩为 `(minY, height)`，**`size_horizontal` / `size_vertical` 删除**；
  - **BlockState JSON 新格式**：不再收 `{"Name": "minecraft:air"}`，收纯字符串 `"minecraft:air"` 或 `{"id": ..., "properties": ...}`——错误信息 `Not a string: {...}; No key id in MapLike` 是判别词，注册表拒启。
- world_preset 路径（`data/<ns>/worldgen/world_preset/` + `data/minecraft/tags/worldgen/world_preset/normal.json`）全线不变。

## 4. 测试面

- mineflayer 协议覆盖（4.39.0 + minecraft-data 3.117.0）：**26.1 线可用**（协议 775，bot E2E 全过）；**26.2/26.3 缺协议定义**（"No data available for version 26.2" / "unsupported protocol version: 26.3"），bot 只能跳过，RCON 断言不受影响。
- 虚空维度近原点 forceload 安全（D7 远块规则继续适用）；forceload 跨重启持久、关服等进程退出（D4）在 26.x 复验成立。
- 26.x fabric-api 内置包 id 有变：server.properties 的 `initial-enabled-packs` 里写 `fabric` 会报 "Missing data pack fabric"——只写 `vanilla` + mod 包。

## 排查方法论

同前：diff 同源代码 → 编译两遍归类错误 → 行为测试兜底。26.x 的特殊性在于**先过工具链断层再谈 API**——build 报 "Failed to find official mojang mappings" 或 "requires Java 25" 时直接跳 §1，不要在旧 Loom 上耗。
